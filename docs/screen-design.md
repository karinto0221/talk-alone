# 画面設計

## 共通

- Tauriのメインウィンドウ内で動作し、画面遷移にはHash Routerを使用する。
- ヘッダーにはアプリ名と `OFFLINE · DESKTOP` を表示する。
- ダークネイビーを基調とし、操作色はブルー、補助色はシアンとする。
- 画面から外部サイト、分析、履歴、設定、ログインへ遷移する導線は持たない。
- ユーザー設定は永続化しない。アプリ再起動時は初期状態へ戻る。

## 練習開始画面

- 4つの練習モードから選択する。初期値はスタンダード。
- スタンダードとワードでは、ランダムまたは内蔵10ジャンルから選択する。
- 配信者では1〜60分の練習時間を設定する。初期値は10分。
- 配信者のコメント頻度は「高頻度（10〜30秒）」「通常（60〜180秒）」「低頻度（180〜300秒）」から選択し、初期値は「通常」とする。
- 瞬発力ではコメント返しまたは例えツッコミを選択する。
- すべての選択肢とコンテンツは端末内にあり、読み込み待ちや通信エラーは発生しない。

## 3分スピーチ

- スタンダードでは選択ジャンルの文章・問い、ワードでは選択ジャンルの1単語をランダム表示する。
- ランダム選択時は先に10ジャンルから1件を決定する。
- 開始時にマイク利用を要求し、許可された場合は録音と3分タイマーを同時に開始する。
- マイク拒否・非対応・録音開始失敗時も、録音なしで練習を開始する。
- 残り時間、進捗、ジャンル、お題、録音状態、ヒント、終了ボタンを表示する。
- ヒントは内蔵候補から取得し、同一セッション内で直前と同じ内容を避ける。
- 3分経過または終了ボタンで録音を停止し、リザルト画面へ移動する。
- 練習結果はDBやファイルへ自動保存しない。

## リザルト

- 直前の3分スピーチのお題、ジャンル、モード、経過時間を表示する。
- 録音がある場合はその場で再生できる。
- 「録音ファイルを保存」でOS標準の保存ダイアログを開き、ユーザーが指定した場所へ音声を書き込む。
- ブラウザでUI確認している場合は、同じ操作を通常のファイルダウンロードとして扱う。
- 録音と結果はReactのメモリ上に1件だけ保持し、練習画面へ戻る際に破棄する。
- アプリ終了、再読み込み、リザルトへの直接遷移でデータがない場合は、練習画面へ戻る案内を表示する。
- AI分析、採点、文字起こし、履歴保存は表示しない。

## 配信練習

- 内蔵コメント5,000件から開始直後に1件表示し、その後は開始前に選んだ頻度の範囲内でランダムな間隔を決め、1件ずつ表示する。
- 直近10件との重複を避ける。
- コメントには内蔵ラジオネームと人型の初期アイコンを付ける。
- 残り時間、コメント数、終了ボタンを表示する。
- 時間到達時は完走時間とコメント数だけを表示する。
- 録音、結果保存、分析は行わない。

## 瞬発力練習

- コメント返しでは内蔵コメント5,000件から表示し、直近10件との重複を避ける。
- 例えツッコミでは「強調表現＋形容詞」「目的語＋動詞」「形容表現＋名詞」の3形式を混ぜて出題する。
- NEXTまたはEnterキーで次へ進み、現在のラウンド数を表示する。
- タイマー、録音、反応速度計測、採点、結果保存は行わない。
