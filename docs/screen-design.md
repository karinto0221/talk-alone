# 画面設計

## 共通

- スマートフォンとPCのブラウザで動作し、画面遷移にはHash Routerを使用する。
- ヘッダーにはアプリ名と `NO ACCOUNT · NO UPLOAD` を表示する。
- ヘッダーのプルダウンで画面言語を日本語 / 英語から選択する。
- ダークネイビーを基調とし、操作色はブルー、補助色はシアンとする。
- 画面から外部サイト、分析、履歴、設定、ログインへ遷移する導線は持たない。
- ユーザー設定は永続化しない。ページ再読み込み時は初期状態へ戻る。
- 画面言語と練習言語は独立しており、日本語UIで英語練習、英語UIで日本語練習も可能とする。初期値は両方とも日本語。
- 760px以下では主要レイアウトを1カラムにし、320px幅まで横スクロールなしで操作できるようにする。
- スマートフォンではSafe Areaを考慮し、主要ボタンの高さを48px以上とする。

## 練習開始画面

- 「スピーチ」「瞬発力」「配信者」の3つの練習モードから選択する。開始画面ではこの順に表示し、初期値はスピーチとする。
- 練習モードは、閉じているときに選択中のアイコン・名称・補足だけを表示する説明付きドロップダウンとする。
- 練習言語を日本語 / 英語から選択し、選択した言語のお題・コメントを使用する。
- スピーチでは、ランダムまたは内蔵10ジャンルから選択する。
- 配信者では1〜60分の練習時間を設定する。初期値は10分。
- 配信者のコメント頻度はプルダウンで「高頻度（10〜30秒）」「通常（60〜180秒）」「低頻度（180〜300秒）」から選択し、初期値は「通常」とする。
- 瞬発力では例え連想または組み合わせツッコミをプルダウンで選択し、初期値は例え連想とする。
- 瞬発力の練習方式はプルダウンで「5問」「10問」「チャレンジ（5問・各10秒・録画）」から選択し、初期値は10問とする。
- すべての選択肢とコンテンツは端末内にあり、読み込み待ちや通信エラーは発生しない。

## 3分スピーチ

- 選択ジャンルの短いテーマと単語を合わせた候補から、1件をランダム表示する。
- ランダム選択時は先に10ジャンルから1件を決定する。
- 開始時にマイク利用を要求し、許可された場合は録音と3分タイマーを同時に開始する。
- マイク拒否・非対応・録音開始失敗時も、録音なしで練習を開始する。
- 残り時間、進捗、ジャンル、お題、録音状態、終了ボタンを表示する。
- 3分経過または終了ボタンで録音を停止し、リザルト画面へ移動する。
- 練習結果はDBやファイルへ自動保存しない。

## リザルト

- 直前の3分スピーチのお題、ジャンル、モード、経過時間を表示する。
- 録音がある場合はその場で再生できる。
- 「録音ファイルを保存」でブラウザのファイルダウンロードを開始する。
- 録音と結果はReactのメモリ上に1件だけ保持し、練習画面へ戻る際に破棄する。
- タブ終了、再読み込み、リザルトへの直接遷移でデータがない場合は、練習画面へ戻る案内を表示する。
- AI分析、採点、文字起こし、履歴保存は表示しない。

## 配信練習

- 内蔵コメント1,000件から開始直後に1件表示し、その後は開始前に選んだ頻度の範囲内でランダムな間隔を決め、1件ずつ表示する。
- 直近10件との重複を避ける。
- コメントには内蔵ラジオネームと人型の初期アイコンを付ける。
- 開始時にマイク利用を要求し、音声を保存せずに発話区間と無音区間を計測する。
- マイク拒否・非対応・取得失敗時も発話分析なしで練習を開始する。
- 残り時間、コメント数、音声計測状態、終了ボタンを表示する。
- PCではコメント欄とタイマーを横並びにし、スマートフォンではコンパクトなタイマーの下でコメント欄が画面の残りの高さを使用する。コメントが増えた場合はコメント欄の内部だけをスクロールする。
- 時間到達または終了ボタンでリザルトへ進む。
- リザルトでは練習時間、完走率、コメント数を表示する。マイクを利用できた場合は、発話時間、発話率、最長連続発話、最長無音、3秒以上の無音回数も表示する。
- リザルトから同じ設定でもう一度開始するか、TOPへ戻ることができる。
- 録音と結果保存は行わない。

## 瞬発力練習

- 例え連想では、文脈を付けずに「修飾表現＋形容詞」を出題し、条件に合うものを素早く連想する。
- 組み合わせツッコミでは「形容表現＋名詞」と「目的語＋助詞＋動詞」を同じ確率で出題し、組み合わせの違和感に一言で返す。
- コメント返しは瞬発力には含めず、配信者モードでコメント対応を練習する。
- 5問と10問は時間制限なしのフリー練習とする。NEXTまたはEnterキーで次へ進み、お題の表示から操作までを回答時間として記録する。
- チャレンジは3秒カウントダウン後に開始し、5問それぞれに10秒の制限時間を設ける。ユーザーはNEXTまたはEnterキーで早く次へ進められ、10秒経過時は時間切れとして自動で次へ進む。
- チャレンジ開始時にマイク利用を要求し、縦9:16のお題UIと音声を動画としてメモリ上に録画する。カメラ映像は含めない。
- マイクを拒否した場合、または「マイクを使わず続ける」を選んだ場合も、音声なしの動画で練習を続ける。録画機能非対応環境でも練習自体は続行する。
- 選択した出題数の完了後、平均回答時間、最速、最長、合計時間、問題別の回答時間を表示する。
- チャレンジのリザルトでは時間切れの問題を明示し、録画できた場合は動画をその場で再生できる。
- チャレンジ動画は「動画を保存」でローカルファイルとして保存できる。ファイル共有対応端末では「動画を共有」からOSの共有メニューを開く。
- 動画を自動保存・送信せず、リザルト画面を離れると破棄する。
- リザルトから同じ設定でもう一度開始するか、TOPへ戻ることができる。
- フリー練習では録音や録画を行わず、どの方式でも採点と結果の永続保存は行わない。
