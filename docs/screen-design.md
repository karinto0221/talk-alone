# 画面設計

## 共通レイアウト

- ヘッダー左にロゴ、中央に「スピーチ」「分析」ナビゲーションを表示する。
- PCではロゴ・中央ナビゲーション・セッション時間を3列表示する。
- 760px以下ではセッション時間を非表示にし、ロゴとナビゲーションをヘッダー内の左右に配置する。
- 520px以下ではロゴ文字を省略してアイコンだけを表示し、320px幅でもナビゲーションと重ならないようにする。
- 色はダークネイビーを基調とし、操作色はブルー、補助色はシアンとする。
- キャッチコピー、絵文字、装飾目的のイラストは使用しない。

## スピーチ画面

- URL: `/`
- 権限: 認証不要

### 開始前

- タイトル、3分間スピーチの簡潔な説明、出題設定、開始ボタン、3分タイマーのプレビューを表示する。
- 出題モードは「スタンダード（文章・問い）」と「ワード（1単語のみ）」から選択する。初期値はスタンダード。
- 両モードで、ジャンルを「ランダム」またはジャンルマスタの10件から選択する。初期値はランダム。
- ランダムの場合、バックエンドがジャンルマスタから1件を選び、そのジャンルに沿ってお題を生成する。
- タイマープレビューには現在選択しているモードとジャンルを反映する。
- 画面表示時にジャンル一覧を取得し、取得中または一覧が空の間は開始ボタンを無効化する。
- 開始ボタン押下後、お題取得中はボタンを無効化しローディング表示にする。
- APIエラー時は画面上部にエラーバナーを表示し、開始前へ戻る。

### セッション中

- 残り時間、進捗バー、ジャンル、お題、出題モード、ヒント表示領域、操作ボタンを表示する。
- 1秒ごとに経過時間を加算し、180秒で自動終了・保存する。
- 「ヒントを表示」は何度でも利用でき、取得中は無効化する。
- 「終了」でその時点の時間を保存する。1秒未満の場合は1秒として保存する。
- 保存中は操作ボタンを無効化する。保存失敗時はセッション中へ戻してエラーを表示する。
- お題取得後にマイク利用を要求し、許可された場合はタイマー開始と同時に録音を開始する。
- 録音中は赤い丸と「録音中」を表示する。
- マイク拒否・非対応・開始失敗時もスピーチは開始し、「録音なし」と案内を表示する。

### 完了

- 手動終了または180秒経過で記録を保存し、リザルト画面へ遷移する。

## リザルト画面

- URL: `/result/:speechId`
- 権限: 認証不要
- 終了したスピーチのお題、ジャンル、出題モード、スピーチ時間を表示する。
- 録音がある場合はブラウザ上で再生し、録音形式に応じた音声ファイルとしてダウンロードできる。
- 録音はメモリ上の一時データであり、DBやサーバーへ保存しない。再読み込み、タブ終了、アプリからの離脱後は再表示できない。
- 録音がない場合はその旨を表示し、「AIで分析」ボタンを無効化する。
- 「AIで分析」押下時だけ録音を分析APIへ送り、処理中はボタンを無効化する。
- 分析完了後は、要約、良かった点、改善できる点、次回の課題を表示する。文字起こしは折りたたみで確認できる。
- AI分析結果も画面内の一時データとし、DBへ保存しない。
- 一時データが失われた状態でURLへ直接アクセスした場合は案内とスピーチ画面へ戻るリンクを表示する。
- 760px以下では録音・分析カードとフィードバックを1列表示する。520px以下ではサマリーの時間欄も1列化する。

## 分析画面

- URL: `/analytics`
- 権限: 認証不要
- 「総合」「スタンダード」「ワード」のタブで集計対象を切り替える。
- 各タブでセッション回数、平均時間、最長時間をカード表示する。
- 総合では、全モードを対象とした直近6か月の月別平均時間だけを詳細グラフとして表示する。ジャンル別集計と履歴は表示しない。
- スタンダードでは、選択ジャンル別の平均時間、月別平均時間、最近のセッションを表示する。
- ワードでは、選択またはランダムで決定したジャンル別の平均時間、月別平均時間、最近のセッションを表示する。
- 最近20件のうち先頭8件を表形式で表示する。
- 読み込み中は中央ローディング、通信失敗時はエラーバナーを表示する。
- 記録がないグラフ・一覧には空状態を表示する。
- 760px以下ではカードとグラフを1列にし、履歴表のジャンル列を省略する。
- 520px以下ではグラフ、ジャンル集計、履歴表の余白と列幅を縮め、横スクロールなしで表示する。
